# 第 002 期 · 那年，那人，那条路

- 原作：`packages/content/posts/that_year_that_person_that_road.md`，2026-07-11，已公开；署名采用主站 `SITE.author` 的 `newmaybe`。
- 作品地址：`/featured/issue-002`，自本期起为 `/featured` 的本期精选；第 001 期保留在往期目录。
- 原诗全文保留，诗句、标点与分节不改。四节的朱印小标“那年”“那条路”“那人”“而今”取自各节首句；末句“风却不是你。”按原文单独成段。开篇的“一条路，记得所有走过它的人。”、进入提示“往下读，就是往前走”、交互提示“拂过或轻触画面，便起一阵风。”与结尾“愿你也有一条，可以重走的路。”为本期编辑文字，不属于原诗。
- 延伸阅读链接《两年的念》来自原作 frontmatter 的 `connections`，同为主站公开文章。
- 诗画一体：画面铺满整屏并固定，诗以竖排题画诗的形式写进画面留白的天空，每节配一枚朱印。各节轮流落在左右两侧的空天里；窄屏统一落在右上方，末句居中。
- 往下读，就是往前走：页面滚动即沿路前行，镜头随之缓慢推进，远山、田野与近处草丛按远近分层放大。
- 叶落成字：每一节的字先以落叶的颜色飘下，落定后化为墨色；读到下一节时，一阵风把字吹散。
- 你是风：鼠标或手指拂过画面会起风，吹动飘落的叶子；轻触画面会抖落一把叶子；末段“风却不是你。”会顺着手势轻轻偏开，再慢慢回到原位。
- 场景随段落切换：路口风轻云淡，那人挥手，手停在半空（“未说出口的半句话”）→ 落叶铺满、日影西斜 → 暮色里那人沿路走远、变小、消失，脚印被落叶盖住 → 而今褪色的旧路上出现“我”的脚印 → 夜风吹过，落叶横飞，末句浮现。
- 画面：内联 SVG 绘制的秋日道路、远山、银杏、落叶与路口的人，飘叶用 Canvas 绘制，全部为本次代码生成（按地面透视计算道路、树木与脚印的大小），无第三方图片、字体请求或追踪脚本。颜色由共享 design tokens 经 `color-mix()` 调出，未新增色值；暗色系统主题下画面整体压暗一层，题字与朱印保持画面本身的颜色。
- 声音：Web Audio 程序生成的风声（棕噪声经带通滤波，阵风随机起伏，强弱随段落变化，末段每十秒一阵，与画面同步）与 Karplus–Strong 拨弦（羽调式五声音阶的稀疏短句，加程序生成的混响），不引用任何录音。拂过画面时风声随之涌起，轻触时有落叶的沙沙声。默认关闭，读者手动开启后才出现音量滑块；离开页面即暂停，返回后需手动重新开启；开启失败时提示仍可继续阅读。
- 动效：落叶与风的动画可用按钮暂停。系统开启减少动态效果时，镜头不推进，不显示飘叶与风线，字直接淡入，那人改为原地淡出。
- 无障碍：逐字动画的字形对读屏隐藏，每节另有完整诗句供读屏连贯朗读；节名为二级标题。关闭 JavaScript 时，画面作为开篇，诗文、导航与链接在其下以纸面排版完整呈现，播放器不出现。
