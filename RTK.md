# RTK usage

RTK is an optional local command-output proxy. The personal instructions referenced
by this workspace are at `~/.claude/RTK.md`; they are not a repository dependency.
Use `rtk --version` to check availability and `rtk proxy <command>` for unfiltered
output when diagnosing a command. Standard commands remain valid when RTK is absent.
Repository guidance continues to live in [CLAUDE.md](./CLAUDE.md).
